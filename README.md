To-Do Tasker – Smart Task Management

📌 About the Project

To-Do Tasker is a simple yet unique task management application designed to help users organise their daily activities. It includes task management features along with a special reminder system that makes it different from an ordinary to-do list.

✨ Features

- ADD: Add new tasks to the task list.
- DELETE: Remove tasks that are no longer needed.
- REMINDER: Displays a reminder popup with a custom message after a 20-second delay.
- TASK COMPLETION: Mark completed tasks using a grey check mark and strikethrough text.
- INTERACTIVE DESIGN: Simple controls for managing tasks.
- COLOURED STATES: Different visual states help identify task status.

🛠️ Technologies Used

- HTML5 – Structures the application.
- CSS3 – Controls the design and appearance.
- JavaScript – Handles task operations, reminders, and interactive functions.

🚀 How to Use

1. Open the application in a web browser.
2. Add a task to your list.
3. Complete tasks when they are finished.
4. Delete tasks that are no longer required.
5. Use the reminder feature to receive a popup notification.

🎯 Project Purpose

The purpose of this project is to create a lightweight and interactive task manager while exploring web development, user interaction, and JavaScript functionality.
