TO-DO TASK WRITTER

USER MANUAL

1. Introduction

Welcome to To-Do Task Writter!

To-Do Task Writter is a task-management application designed to help users remember, organise and complete their daily activities.

It provides features such as task creation, completion, reminders, pinning, moving and deleting tasks.

This manual explains how to use the application step by step.

2. Input Text or Adding Task

The input text field allows users to write new tasks.

How to add a task:

1. Find the input field labelled "Write your task".
2. Type the task you want to remember.
3. Press the green ADD button.
4. Your task will appear in the task list.

Example: Write "Complete mathematics homework" and press ADD.

Note: Empty tasks cannot be added.

3. Complete Task

The Complete feature helps users identify finished tasks.

How to complete a task:

1. Find the task you have finished.
2. Press the circular button on its left side.
3. A tick mark will appear.
4. The task text will become crossed out.

This indicates that the task has been completed.

Press the circular button again to mark the task as unfinished.

Reminder behaviour: When a task is completed, its active reminder is stopped and the reminder button becomes disabled.

4. Adding and Deleting Tasks

This section explains how to add new tasks and remove unwanted tasks.

A. Adding a Task

Follow the instructions in Section 2 to create a new task using the input field and ADD button.

B. Deleting a Task

There are two ways to delete tasks.

Method 1: Using the Task Menu

1. Find the task you want to delete.
2. Click and hold the task for approximately 600 milliseconds.
3. The task menu will appear.
4. Select Delete.
5. The selected task will be removed.

Method 2: Using the DELETE Button

1. Select a task by clicking it.
2. Press the red DELETE button.
3. The selected task will be removed.

If no task is selected, the DELETE button removes the last task in the list.

5. Using Reminder

The Reminder feature helps users remember their tasks.

How to activate a reminder:

1. Find the task for which you want a reminder.
2. Press its yellow Reminder button.
3. Wait for 20 seconds.
4. A reminder popup will appear with the task text.
5. A sound will also play.
6. Press OK to close the reminder and stop the sound.

Important points:

- Each task has its own Reminder button.
- A reminder cannot be activated for a completed task.
- A second reminder cannot be started while the first one is active.
- Completing a task stops its active reminder.

6. Using Menu

The task menu provides three options for managing individual tasks.

How to open the menu:

1. Find the required task.
2. Click and hold it for approximately 600 milliseconds.
3. The menu will appear near your touch or pointer position.

The menu contains three options in this order:

A. Pin

The Pin option highlights an important task.

When pinned, the task gets a golden border and a light yellow background.

Press Pin again to remove the pin.

B. Move

The Move option allows users to change the position of a task.

How to move a task:

1. Open the task menu.
2. Select Move.
3. A message will appear: "Drag the selected task to another position."
4. Drag the selected task to the required position.
5. Release it to finish moving.

C. Delete

The Delete option removes the selected task completely.

To use it, open the task menu and select Delete.

Remember the menu order:

1. Pin
2. Move
3. Delete

---

Conclusion

To-Do Task Writter provides an easy way to manage everyday activities.

Users can create tasks, mark them as completed, set reminders and organise their task list using the Pin and Move options.

We hope this manual helps you understand and use To-Do Task Writter.

Thank you for using To-Do Task Writter!
